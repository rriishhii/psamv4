About this app

Property Survey & Assessment Manager (PSAM) is a data entry tool for Urban Local Bodies. It is used to record property details ward by ward and floor by floor.

  • Keeps a record for every property, identified by Ward and GIS ID.
  • Records floor-by-floor details for the selected ULB.
  • Produces ward-wise reports.
  • Imports and exports property data as an Excel sheet.

Import / Export Excel

One sheet per ward (the sheet name is the ward, e.g. Ward 9) and one row per property. Each floor has its own columns (Zone, Building Type, Year, Occupancy, Area, Remarks). When a floor has several entries, put them in the same cell separated by a pipe ( | ), in the same order in every column, for example SELF RESIDENTIAL | SHOPS and 83.79 | 66.36. N/A means blank. Any Yes/No column in an older file is ignored. Existing properties (same Ward + GIS ID) are updated; new ones are added. The Tax, S.No and date columns are ignored on import.
